# GenAI Resume Assistant 🚀

A Generative AI–based application that analyzes resumes against job descriptions and provides skill gap analysis, ATS improvement suggestions, and actionable recommendations.

## Features
- Resume vs Job Description matching
- Skill gap identification
- ATS improvement suggestions
- AI-powered insights using LLMs

## Tech Stack
- Python
- Streamlit
- Generative AI (LLMs)
- Prompt Engineering

## How to Run
1. Clone the repository
2. Create virtual environment
3. Install dependencies:
   pip install -r requirements.txt
4. Run:
   streamlit run app.py
